# TRPG OS Architecture

## Overview
Python FastAPI based autonomous TRPG campaign manager.

## Core Components
- StateManager: xlsx + SQLite hybrid
- SessionHandler: LLM + rules engine
- Temporal Reasoning & Eviction Policy
- Lorebook-style World Facts

## Design Goals
- Long-term consistency
- Emergent narrative with guardrails
- Easy human override
- Version control via GitHub
